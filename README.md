# AETHER CLASH

**Epic Browser-Based 3D Anime Fighting Game** built with Three.js

![AETHER CLASH](https://via.placeholder.com/800x400/1a0033/00ffff?text=AETHER+CLASH)

## Features
- Real-time 3D anime fighters
- Fluid movement & combat
- Special power effects (Fire + Shadow)
- Dynamic camera
- JSON-based character system
- Ready for GitHub Pages

## Controls (Player 1)
- **A / D** - Move Left / Right
- **W / S** - Move Forward / Back
- **J** - Light Attack (Flame Slash)
- **K** - Heavy Attack
- **L** - Special Attack (Blazing Wave)
